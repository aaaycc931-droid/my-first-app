# 历史研究与讨论归档

本目录保存项目的历史研究与讨论资料，用于技术侦察、路线追溯和避免重复调研。

这些归档不是当前代码状态、产品功能完成声明或法律意见。下列动态信息在执行前必须重新核验：

- GitHub 项目状态；
- 开源许可证；
- 法律法规；
- 平台政策；
- 云服务价格；
- 支付渠道资格；
- 爱发电等第三方平台功能。

当前实施必须以仓库的正式路线、状态矩阵、ADR、测试和 Definition of Done 为准。研究归档中相互冲突的历史建议，应以时间更晚且已经写入正式决策记录的结论为准。

从归档中采纳新技术前，必须创建 Technology Candidate 或 ADR，并明确记录：

- 用户价值；
- 许可证；
- 数据和模型来源；
- 中国区影响；
- 隐私和安全风险；
- PoC 指标；
- 回滚方案；
- 是否阻塞当前发布。
