# V1 账户结构化数据导出验收边界

状态：**Implementation candidate**

QA level recommendation：**strict**

## 用户闭环

已登录用户可在账户页主动点击“下载账户数据”。系统读取当前账户在现有 RLS
边界内可见的私人资料、用户自建练习、练习会话与记录、评测结果、技能进度、复练
队列、私有素材清单、分析任务、乐谱草稿、同意记录和删除请求，并下载一个
`schemaVersion: 1` 的 UTF-8 JSON 文件。

导出包记录账户 ID、邮箱、账户创建时间、生成时间和显式 allowlist 的结构化字段。
文件名不包含邮箱或用户 ID。私有素材只导出数据库清单，不下载或嵌入原始音频、
图片、PDF 或其他对象二进制。

## 失败关闭

- 每个直接带 owner 字段的查询同时以当前会话 user ID 过滤，并继续由 RLS 授权；
- `evaluation_results` 继续通过既有 attempt ownership RLS 间接限定；
- 任意一张表读取失败时，整个导出失败且不触发部分文件下载；
- 重复点击在导出进行中禁用；失败后可重试；
- 下载失败不修改、删除或标记任何服务器数据。

## 明确不在本切片

- 账户删除、级联数据库删除、Storage 对象删除或 24 小时删除 SLA；
- 原始私有素材文件的归档包、异步导出任务或邮件通知；
- 生产跨用户越权演练、真实浏览器下载重开、键盘／屏幕阅读器、目标用户验收；
- 把 V1-03 标记为 `PASS`。

上述项目仍需独立实现和真实执行。本切片只能把 V1-03 从完全未实现推进为结构化
导出 implementation candidate，不能冒充完整数据生命周期闭环。

## 自动验证

- 导出包版本、生成时间、稳定文件名和素材清单；
- 12 张表恰好查询一次，11 张直接 owner 表显式绑定当前 user ID；
- 字段显式 allowlist，不使用 `select('*')`；
- 单表失败阻止整个导出；
- Quality workflow 覆盖新增 focused test；
- typecheck、lint、生产构建、仓库卫生和 Android 本地门禁。

真实浏览器、生产 RLS、Android 真机、可访问性、教师和目标用户 QA 仍为
`NOT_EXECUTED`。
