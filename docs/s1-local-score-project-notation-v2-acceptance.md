# S1 本机谱项目附点、延音线与歌词验收

## 完成范围

- 仅把本机谱项目内容升级为 `score-document-v2`，存储信封升级为
  `local-score-project-storage-v3`；通用 `ScoreDocumentEventV1` 与其他练习文档保持不变。
- 旧 v1 / v2 本机谱项目在读取时确定性迁移到内存，不因列表或打开而写回；
  用户下一次明确保存成功后才持久化 v3。读取迁移不改变 revision、时间戳或历史语义。
- 音符支持一个附点、到下一事件的延音线和最多 80 个 Unicode code point
  的单行歌词；休止符支持一个附点，不支持延音线和歌词。空歌词规范化为 `null`，
  控制字符和超长歌词以简体中文拒绝。
- 附点时值按基础时值的 1.5 倍计算，并统一用于小节容量、谱面布局和播放时间线。
- 延音线只连接同一声部中相邻、同音高的两个音符，可跨连续小节；不能连接休止符、
  不同音高、不同声部或末尾事件。会破坏延音关系的修改、移动或删除必须在保存前拒绝。
- 单事件复制保留附点和歌词，但主动清除延音线并以简体中文说明；不把跨事件关系
  暗中复制到新位置。
- 五线谱预览显示附点、延音弧和歌词，并提供对应无障碍名称。
- 播放时延音链只产生一次起音和一次止音；播放光标仍逐事件推进并保持生命周期清理。
- UI 允许创建和修改附点、延音线与歌词；所有修改继续遵守 save-first，写入失败时
  不发布未保存状态。

## 必须测试

- v1 / v2 读取迁移、无读时写回、显式保存后 v3 持久化，以及迁移前原始数据完整。
- 附点容量的未达到、正好达到和超过边界。
- 合法同音相邻延音、跨连续小节延音，以及休止符、不同音高、不同声部、末尾和断裂关系拒绝。
- 会破坏延音关系的修改、移动、删除失败后，已有项目与 UI 保持不变；修正条件后可重试。
- 歌词空值规范化、Unicode code point 上限、控制字符和超长拒绝。
- 复制保留附点/歌词并清除延音；粘贴仍遵守容量、CAS、quota、普通写入和事务失败保护。
- 谱面呈现、ARIA、附点时长、延音播放链、逐事件光标和清理。

## 明确不做

- 双附点、三连音或其他连音分组。
- 圆滑线（slur）、跨声部延音、复杂歌词排版、连字符或 melisma。
- MusicXML 导入导出、通用 `ScoreDocument` 全局迁移或 IndexedDB store 升级。
- 云同步、账号、自动清理、付费扩容或与本切片无关的大规模 UI 重构。
- P119d 状态变更；逐题六维教师审核和教育有效性仍为 `NOT_EXECUTED`，
  正式评估门禁仍为 `BLOCKED`。
